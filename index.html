    번호는 어떻게 뽑나요?

    1부터 45까지 45개의 번호를 피셔-예이츠(Fisher-Yates) 셔플로 고르게 섞은 뒤, 앞의 6개를 본번호로, 7번째를 보너스 번호로 사용합니다. 모든 번호가 뽑힐 확률은 똑같고, 과거 당첨 번호나 특정 패턴을 반영하지 않는 순수한 무작위 방식입니다. 뽑은 번호는 서버로 전송되거나 저장되지 않고, 새로고침하면 기록도 사라집니다.

    등수별 당첨 확률

    로또 6/45의 전체 조합 수는 8,145,060가지입니다. 한 게임 기준 확률은 다음과 같습니다.

    등수당첨 조건확률
    1등6개 번호 일치1 / 8,145,060
    2등5개 + 보너스 번호 일치1 / 1,357,510
    3등5개 번호 일치1 / 35,724
    4등4개 번호 일치1 / 733
    5등3개 번호 일치1 / 45

    "자주 나온 번호"나 "연속 번호를 피하는 조합"도 당첨 확률은 다른 조합과 같습니다. 어떤 조합이든 1등 확률은 약 814만 분의 1이니, 재미로만 즐겨주세요.
